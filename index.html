Mémo Révision — Cours Pr. Zaidan Didi

1. Introduction GNU/Linux & Prompt

• GNU (GNU is Not Unix, acronyme récursif) lancé en 1983 par Richard Stallman (FSF 1985, Copyleft/GPL, Emacs, GCC, GDB).

• Noyau Linux créé en 1991 par Linus Torvalds (étudiant à Helsinki). GNU + Linux = GNU/Linux.

• Prompt zaidan@pcz:~$ : zaidan (utilisateur), @ (sur), pcz (machine/hostname), ~ (/home/zaidan), $ (utilisateur standard, devient # pour root).

2. Comptes & Droits d'accès

• /etc/passwd (7 champs) : login:passwd:uid:gid:comment:home:shell. UID de 0 à 65535 (0-99 réservés système).

• Commandes : id, whoami, chfn (champ 5), groups, newgrp, chown, chgrp.

• Octal chmod : r = 4, w = 2, x = 1. Droits max par défaut : Répertoire = 777, Fichier normal = 666. Formule : droits_effectifs = droits_max - masque (umask).

3. Automatisation (cron, at, sleep)

• cron (service cron) : tâches répétitives dans crontab -e. 6 champs : Minutes(0-59) Heures(0-23) JourMois(1-31) Mois(1-12) JourSemaine(0-7) Commande. Contrôle : /etc/cron.allow puis /etc/cron.deny.

• at (service atd) : exécution unique (at 21:20 puis Ctrl+D, at -f script.sh now + 2 days, atq, atrm N).

• sleep : pause (sleep 10 = 10s, 2m = 2 min, 3h = 3 heures, 7d = 7 jours).

4. Réseau Ubuntu (Netplan & ping)

• Fichiers YAML dans /etc/netplan/ (indentation avec des espaces, jamais de tabulations !). networkd (Server) vs NetworkManager (Desktop).

• Commandes : ip link show, sudo chmod 600 /etc/netplan/*.yaml, sudo netplan generate, sudo netplan try (rollback auto si non confirmé), sudo netplan apply.

• ping (ICMP Echo Request / Echo Reply) : -c N (nombre), -q (quiet/bilan), -i S (intervalle), -W S (attente réponse), -w S (durée max). Diagnostic : 127.0.0.1 → passerelle 192.168.1.1 → distant 1.1.1.1.
